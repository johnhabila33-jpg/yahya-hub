# Yahya Hub 🚀

### A Modern Digital Learning and Community Platform

Yahya Hub is a digital platform designed to provide users with an interactive and user-friendly experience.

## ✨ Features

- User registration and login
- Forgot password functionality
- Verification code interface
- Interactive user dashboard
- Responsive user interface
- Modern navigation and design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

The project contains frontend files responsible for the website's structure, styling, and functionality.

## 🎯 Project Goal

To create a modern digital platform that improves user experience and makes accessing digital services easier.
